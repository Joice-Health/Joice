Product documentation for the Joice platform: one page per feature, in plain language, for
the whole team.

Every page follows the same shape: what the feature is and who it is for, how to use it
today, a picture of how it works, links to the deeper material, and a changelog that grows a
row whenever the feature changes. Pages are updated as part of shipping, so what you read
here matches what is live.

Want more depth on anything? Each page links to the engineering documentation on GitHub and,
where one exists, the Shortcut epic that tracked the work.
