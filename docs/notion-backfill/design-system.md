# Design system

## What it is / Who it's for

How Joice looks and why: warm cream paper, dark olive text, three typefaces from the Dinamo
foundry all in their Light weight, square brackets and dotted-outline buttons as the house
devices. For anyone making something that carries the Joice brand: site pages, decks, social
graphics, emails.

## The essentials

| Element | The rule |
|---|---|
| Background | Cream paper, not white; white is reserved for panels sitting on the cream |
| Text | Dark olive-grey, never pure black; warm grey is for fills and rules, never for text |
| Olive | An accent, not a body color: the announcement bar, focus rings, small dots |
| Gold gradient | Reserved for the membership card only |
| Typefaces | ABC Ginto for text, Ginto Nord Condensed uppercase for short charismatic statements, Gaisyr Mono uppercase small for labels, nav, and buttons |
| Emphasis | Never bold. Use size, case, or a bracket; the site literally cannot render bold |
| Brackets | Square brackets mark a variable in the system: [ you ], [ 01 ], [ get started ] |
| Buttons | Dotted-outline pills with a small mono label; forward actions end in " +" |
| Structure | Hairline rules and open lists, not cards, shadows, or glass; big images get soft corners, everything small is a pill |

## How to use it

1. Building in the product: use the shared components and theme tokens; do not hand-pick
   colors. Engineering keeps them in one place so the whole site changes together.
2. Making something outside the product (deck, social, print): pull the palette and type
   rules from the full spec linked below; when in doubt, more cream, less olive.
3. Photography is still landing; the organic green field you see in image slots is the
   intentional placeholder, not a bug.
